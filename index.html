About this dashboard

This dashboard explores development indicators for selected countries over time, using data from the World Bank.

Open the data analysis

About the dataset

Source: World Development Indicators (WDI), World Bank. The dataset contains yearly values for several indicators (for example GDP per capita, life expectancy and population) across a group of countries.

What you can do

  • Compare countries in a chosen year
  • Follow how an indicator changes over time
  • Filter the data by country, indicator and year range
